# Boss高情商回复助手

一个面向 Boss 直聘聊天场景的 Chrome/Edge Manifest V3 插件 MVP（当前版本 1.6.3）。

## 当前功能

- 在聊天输入框旁注入“✨ 高情商回复”按钮
- 读取当前页面最近的聊天文本
- 按回复目的、语气和长度生成 3 条回复草稿
- 复制回复或插入聊天输入框
- 访问 Boss“我的简历”页面时自动读取在线简历，不再要求重复填写个人信息
- 识别附件管理中的 PDF/DOC/DOCX 文件名，并尝试读取网页已展开的附件预览文本
- 在聊天助手面板拖入 PDF 或 DOCX 简历并在浏览器本地解析
- 将在线简历和附件简历分源提交给模型，由模型对齐共同信息并规避冲突信息
- 助手窗口关闭时不读取岗位；打开助手并在左侧选择聊天后显示当前岗位摘要
- 按岗位缓存完整 JD；助手打开时切换 HR 才匹配或读取新岗位，设置页可查看缓存数量
- 最多保存最近使用的 5 个完整 JD；超过上限自动删除最久未使用的缓存
- 用户手动打开 Boss 职位详情页后，插件自动读取最新完整 JD，不模拟点击或自动创建/关闭职位标签页
- 在页面加载聊天数据时捕获职位 ID、职位路由或接口中的岗位候选信息，用于匹配手动打开的详情页
- 当链接不可见时，按岗位名称及摘要自动关联本地已缓存的完整 JD
- 缓存前校验页面标题与 JD 结构，自动拒绝并清除 `Oops!`、404、安全验证等异常页面
- 实时监听当前聊天切换，自动刷新上下文并清除上一位 HR 的生成结果
- 按 Boss 实际格式组合职位加密 ID 与 `securityId`，避免把访问令牌误作路径而进入错误页
- 将用户手动打开的职位详情页按真实职位 ID缓存，完整 JD 自动同步到匹配的当前 HR 会话
- 活动聊天识别优先选择与输入框位于同一面板的“查看职位”，防止切换后继续沿用上一岗位
- 切换 HR 时给当前聊天的“查看职位”组件建立跨脚本标记，避免 Boss 保留的旧聊天 DOM 干扰岗位探测
- 完整 JD 标题必须与当前岗位摘要一致，不匹配的旧缓存不会显示或提交给模型
- 在设置页选择魔搭社区或阿里云百炼，并分别保存 API Key、接口地址和模型名称
- 回复按钮固定在当前聊天输入区底部；助手窗口标题栏可拖动，位置会自动记忆
- 通过后台 Service Worker 调用模型，插件页面不直接发起跨域请求

未填写 API Key 时使用本地规则生成；填写后会调用当前选中的 OpenAI 兼容 Chat Completions 接口，并在接口失败时自动降级到本地模板。

打开助手面板不会调用模型。只有用户主动点击“生成回复”时才会生成，避免无意消耗 API 免费额度。

岗位读取也不会调用大模型：只有助手窗口打开且用户在左侧选择聊天后，插件显示当前岗位摘要。请手动点击聊天中的岗位名称或薪资区域打开职位详情页，详情页加载完成后插件会自动提取并缓存完整 JD；用户手动打开的页面保持打开，插件不再模拟点击、自动新开、切换或关闭职位页。同一岗位默认复用本地缓存，最多保存最近 5 个完整 JD。

助手窗口打开时，切换左侧联系人会刷新聊天内容并读取聊天记录。

## 安装

1. 打开 Chrome/Edge 的扩展管理页。
2. 打开“开发者模式”。
3. 选择“加载已解压的扩展程序”，选择本目录 `D:\bosshelper`（必须选到包含 `manifest.json` 的这一层）。如果使用压缩包，请先解压，再选择解压后的 `boss-high-eq-reply-assistant-mvp` 文件夹，不要选择它的上级目录。
4. 打开 `https://www.zhipin.com/` 的聊天消息页面并刷新。

## 注意

- 生成结果是草稿参考，插件不会自动发送。
- 在扩展设置页选择魔搭社区或阿里云百炼并填写对应 API Key。魔搭默认接口为 `https://api-inference.modelscope.cn/v1/chat/completions`；百炼默认接口为 `https://dashscope.aliyuncs.com/compatible-mode/v1/chat/completions`。魔搭社区模型名称必须是对应账户可支持API调用的模型，阿里云可以不填模型名称，有免费体验。
- 访问 Boss 的“我的简历”页面后会自动读取；聊天助手侧栏会显示在线简历状态。
- 可在聊天助手的上传框中选择或拖入最多 3 份简历附件。PDF 和 DOCX 在本地解析；旧版 DOC 文件请先另存为 DOCX 或 PDF；扫描版 PDF 需要先进行 OCR。
- 打开助手并在左侧选择聊天后，助手会读取当前岗位摘要；请手动打开对应职位详情页，插件会自动读取并在面板中显示“完整岗位”。
- API Key 保存在浏览器扩展本地存储中，不要把插件目录或配置截图分享给他人。
- 本项目不会代用户发送消息；生成内容仅作为草稿，使用前请自行核对事实、隐私和表达。
- 使用本项目时请遵守 Boss 直聘、模型服务商及所在地区的相关服务条款；不要上传未经授权的个人或他人敏感信息。
- Boss 直聘页面结构可能变化，若按钮没有出现，需要更新 `content.js` 中的输入框选择器。
- 如果页面启用了 AI 筛选等新版布局，插件会优先按当前输入框所在聊天区域读取消息，并排除筛选、推荐和工具栏文字。
- 聊天内容提取采用限量扫描和短时缓存，避免首次生成回复时页面卡顿。
- 兼容含 AI 筛选卡片的新版布局：优先使用可见的 `#chat-input`，避免误选隐藏的输入模板。
- 更新代码后，在 `edge://extensions` 点击扩展的“重新加载”，再刷新 Boss 直聘聊天页。
- 上线前应补充隐私政策、敏感信息脱敏、服务端鉴权与请求限流，并确认符合平台用户协议。
