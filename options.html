插件设置

配置一个大模型服务后，会根据 HR 对话、岗位信息、Boss 在线简历和附件简历动态生成回复。支持魔搭社区和阿里云百炼；只有点击“生成回复”或“测试连接”时才会调用 API。

大模型 API

API Key 只保存在当前浏览器的扩展本地存储中。请勿把 Key 分享给他人；如担心泄露，可随时在对应平台控制台撤销并重新生成。

Boss 在线简历

访问一次 Boss 直聘“我的简历”页面后，插件会自动读取并在本地保存在线简历，无需点击同步。PDF/Word 附件请直接拖入聊天页的助手面板进行本地解析。

尚未自动读取访问 Boss 简历页后将自动读取。

Boss 岗位读取

助手窗口关闭时不会读取岗位。打开助手后，请在左侧选择聊天，再手动点击聊天中的岗位名称或薪资区域打开 Boss 职位详情页；详情页加载完成后插件会自动读取最新 JD 并缓存，最多保存最近 5 个完整 JD。插件不会模拟点击、自动新开或关闭你手动打开的职位页，也不会调用大模型。

尚未读取岗位打开助手窗口并在左侧选择聊天后读取。
